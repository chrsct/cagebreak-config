### Keybinds
**Reminder**: You have to press MOD(Windows key) + q before you perform an `<action>`.
#### Example
* **Mod+q + `<action>`**
#### Action
* **q** : open a terminal
* **w** : open a chromium
* **c** : close an application
* **M** : leave cagebreak
* **a** : show date and time
* **s** : split vertical
* **S** : split horizontal
* **Q** : Only a specific application on your screen
* **b** : show battery status

#### Workspace
**Reminder**: You DONT have to press MOD(Windows key) + q to perform an `<action>`.
**Mod+1** : Go to Workspace 1
* **Mod+2** : Go to Workspace 2
* **Mod+3** : Go to Workspace 3
* **Mod+4** : Go to Workspace 4
* **Mod+5** : Go to Workspace 5
* **Mod+6** : Go to Workspace 6
* **Ctrl+1** : Move an Application to Workspace 1
* **Ctrl+2** : Move an Application to Workspace 2
* **Ctrl+3** : Move an Application to Workspace 3
* **Ctrl+4** : Move an Application to Workspace 4
* **Ctrl+5** : Move an Application to Workspace 5
* **Ctrl+6** : Move an Application to Workspace 6
